
# MERN
This Web Aplication is built by MongoDB Express React Nodejs

![MERN](https://github.com/Yadzim/MERN/blob/main/client/public/MERN.png?raw=true)

#### Run Aplication:

Run client
```bash
cd client
```
```bash
yarn start
```

Run server

`open new terminal`

```bash
cd server
```
```bash
yarn run dev
```
